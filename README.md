# PolyU Life Simulator V1

Original light interface. An independent, unofficial student game about fourteen weeks of university life.

Play: https://bbppzh.github.io/PolyU-life-simulator-V1/

The homepage opens directly into the game. All game code, styling and assets are embedded. No version selector or login is required. Download `PolyU-Life-Simulator.html` for offline desktop play. On iPhone, open the website in Safari; the Files preview may not run JavaScript.

Events, prices and grades are fictional. This is not an official university service or real GPA. Progress resets when the page is refreshed or closed.
